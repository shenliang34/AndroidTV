# 断线恢复与续播验收

TV 通过 `/api/device` 的 deviceId 区分手机；NSD 名称仅用于处理发现事件。
重连按 1、2、5、10 秒间隔尝试，每次使用最新发现地址并校验身份、重新读取片库。
播放中的网络错误和当前手机的 NSD 丢失事件会触发恢复；耗尽尝试后显示重试入口。
授权失效时提示重新连接确认，视频取消共享后提示返回列表。

播放进度按 deviceId + videoId 保存，每 5 秒、暂停、进入后台、切片及退出时更新。
完成播放会清除进度；播放器尚未取得有效时长时保留已有记录。
首次访问会迁移当前 IP 对应的旧进度；已经更换 IP 的旧记录无法可靠确定归属。

## 实机验证（待执行）

1. 配对后播放到一分钟，暂停、返回，再次打开应出现继续播放提示。
2. 选择继续后切换下一部、上一部，不能继承前一视频的起播位置。
3. 播放期间关闭手机共享，再开启；重新发现同一手机后应恢复到断线位置。
4. 在同一局域网更换手机 IP，确认地址更新且同名的另一手机不能接管播放。
5. 暂停后断网并恢复，播放器应保持暂停；播放中恢复应继续播放。
6. 断网超过自动重试周期，确认重试/返回均可操作，返回后不会自动跳回播放器。
7. 手机撤销授权，恢复时应提示重新确认；取消视频共享时应提示视频不可用。
8. 播放超过 10 秒后强制结束 TV 进程，重新连接后进度应接近最后一次周期保存位置。
9. 播放结束后重新打开应从头开始；进入后台后重新打开应保留进度。

当前改动尚未通过 Android 编译和实机验收；开发机器未配置 JDK / Android SDK。
